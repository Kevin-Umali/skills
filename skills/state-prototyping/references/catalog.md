# Optional catalog: skills and MCP servers

Offer the few that fit; the user picks or chooses none. Load nothing by default. User-named helpers get the same treatment. Confirm a helper is installed or connected, and read it, before relying on it.

| Name | Use for |
| --- | --- |
| `tactile-design` | Layered, quiet product UI: hierarchy, forms, menus, light and dark |
| `interaction-design` | Microinteractions, feedback states |
| `better-interface` | Ranked whole-interface review; then one domain each: `better-accessibility`, `better-colors`, `better-layout`, `better-typography`, `better-ui` (surfaces, icons, motion), `better-writing` (labels, errors, empty states) |
| `emil-design-eng`, `animate`, `animate-expo` (React Native), `animation-vocabulary`, `find-animation-opportunities`, `improve-animations`, `review-animations` | Motion craft, naming, audits |
| `prototype`, `pick-ui-library` | Only on an explicit request for alternatives behind a picker, or a UI library choice |
| `transitions-dev`, `transitions-polish`, `transitions-ui-generation` | Ready-made web transitions, tuning, explicit generation-style reveals |
| `shadcn` | Projects already on shadcn |
| `ui-review` | Critique of a screen, flow or prototype |
| `unslop-ui` | Refining generic-looking UI (name may differ from upstream `unslop`) |
| MCP `devlibs` | Search and read open-source UI components, install plans per library (`search_components`, `get_component`, `get_install_plan`, `get_library_setup`, `list_libraries`) |
| MCP `ruixen-mcp` | Ruixen UI registry (`searchRegistryItems`, `listRegistryItems`, `getRegistryItem`) |

MCP components belong to the prototype: keep each licence with its code and follow the server's setup. Never swap an existing product's own components for them, and a lookup does not authorize a redesign.

## Missing helpers

Explain its role and ask before adding it. Adding a skill or connecting an MCP changes the user's configuration, so never do either silently and never invent a source, package or command. Verify the upstream and its instructions first; if you cannot, say so and ask for a trusted source. A missing helper never blocks the work.
